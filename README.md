# Gamified Portfolio

A unique, game-centric portfolio website built with React, Vite, and Framer Motion.

## Concept
The design is inspired by modern sci-fi game interfaces (HUDs). 
- **Lobby**: The landing page / main menu.
- **Profile**: Character stats and skills.
- **Missions**: Project showcase ("My Works").
- **Comms**: Contact form and social links.

## Tech Stack
- **Vite**: Fast build tool.
- **React**: UI library.
- **Framer Motion**: For smooth animations and transitions.
- **React Icons**: For iconography.

## How to Run
1. Install dependencies:
   ```bash
   npm install
   ```
2. Start the development server:
   ```bash
   npm run dev
   ```
3. Build for production:
   ```bash
   npm run build
   ```

## Customization
- Edit `src/components/Profile.jsx` to update your skills and bio.
- Edit `src/components/Missions.jsx` to add your real projects.
- Edit `src/components/Comms.jsx` to update your social links.
